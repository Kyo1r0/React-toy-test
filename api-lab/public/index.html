0 APIとは何か

APIは「決まった住所に、決まった形でお願いすると、決まった形で返事が来る窓口」です。 人間向けのWebページがHTMLを返すのに対し、APIはプログラム向けにデータ（JSON）を返します。

あなたのブラウザクライアント
リクエスト ──▶ GET /api/hello?name=Kyo
サーバーAPI
レスポンス ◀── 200 OK + {"message":"こんにちは…"}

① エンドポイント

どこに頼むか。URL。/api/hello

② メソッド

何をしたいか。GET=取得 / POST=作成

③ ステータスコード

結果の要約。200成功 / 404無い

④ ボディ

実際のデータ本体。ふつうJSON。

以降のセクションで、この4つが実際にどう動くかを見ます。右の通信ログと、 サーバーを起動したターミナルの出力を見比べると「同じ通信を両側から見ている」ことがわかります。

3 早見表

メソッド

GET取る。何回やっても状態は変わらない。ボディは無い。
POST作る・送る。ボディにJSONを入れる。叩くたびに増える。
PUT / PATCHまるごと置き換え / 一部だけ更新。
DELETE消す。

ステータスコード

2xx成功。200 OK / 201 Created / 204 No Content
4xx頼んだ側のミス。400形式が変 / 401合言葉が無い / 404そんなものは無い
5xxサーバー側のミス。500内部エラー / 502上流のAPIがこけた

ブラウザから直接 vs サーバー経由

直接サーバー経由
速さ速い（1往復）やや遅い（2往復）
CORS相手が許可していないとブラウザに止められる関係ない（CORSはブラウザだけのルール）
レスポンスヘッダー数個しか読めない全部読める
APIキーコードに書くと丸見えサーバーに隠せる
